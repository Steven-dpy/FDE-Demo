# 截图放置说明

把截图存到**本目录**，文件名必须和下面一致。存好后刷新 `index.html`，图片会自动出现
（没放的会显示虚线占位框，不影响排版）。

## 需要 8 张

| 文件名 | 截什么 | 怎么截 |
|---|---|---|
| `01-store.png` | **店铺页首屏** | 打开 http://127.0.0.1:8770/ ，截到 Hero 区 + 一行商品卡。要能看到右下角的 Nook 按钮 |
| `02-category.png` | **分类筛选后** | 点顶部「沙发」或 chips 里的分类，截商品网格。证明 240 SKU 是真的 |
| `03-widget-open.png` | **Nook 打开初始态** | 点右下角按钮，截开场白 + 快捷问题 chips |
| `04-bundle.png` | ★ **场景组包结果** | 点快捷问题「我想弄个能窝着看书的地方」，等出结果后截图。要包含：阅读角说明 + 三件商品 + 每件的理由 + 双币价格 |
| `05-budget.png` | ★ **预算重配** | 紧接着输入「预算一万」，截图。要能看到理由里的「在你 ¥10,000 的预算内」 |
| `06-lang.png` | **中英对比** | 切到 EN 再问一次，截一张英文结果。可以和中文结果拼成左右两张 |
| `07-embed.png` | ★ **深色站嵌入** | 打开 http://127.0.0.1:8770/embed.html ，**先把 Nook 打开**再截图。要能同时看到深色页面和 Nook 的绿色面板 |
| `08-tests.png` | **测试输出** | 见下方命令，截终端输出 |

★ 是整套材料里最有说服力的三张。

## 截测试输出

```bash
cd nook/app
python selfcheck.py            # 16 项
python test_api.py             # 17 项（需先起服务）
```

两个都跑，截最后带 `RESULT:` 的那几行，或者全截。

## 截图建议

- **用浏览器缩放 100%**，别用 125%，否则字会发虚
- **窗口宽度 1440 左右**最合适，太宽商品卡会拉得很难看
- 用 `Win + Shift + S` 截，直接框选
- 存成 **PNG**，不要 JPG（文字边缘会糊）
- Nook 面板的截图，建议**单独截面板**（含一点页面背景），不要截整个屏幕
