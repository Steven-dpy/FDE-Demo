# Nook 作品集

**一份源文件，两种输出。**

| 格式 | 怎么做 | 用途 |
|---|---|---|
| **网页版** | 直接打开 `index.html`；或推到 GitHub Pages | 简历里放链接，HR 点开就能看 |
| **PDF 版** | 浏览器打开 → 点右上角「导出 PDF」（或 `Ctrl+P`）→ 目标选「另存为 PDF」 | 附在简历里、微信直接发给 HR |

打印样式已经调好了：A4、页边距 15mm、封面单独一页、图表不会跨页断开、深色代码块会自动转成浅色底。

---

## 使用步骤

### 1. 先起服务，截 8 张图

```bash
cd ../app && python server.py 8770
```

截图清单和文件名要求见 [`img/README.md`](img/README.md)。

### 2. 把截图丢进 `img/`

文件名对上就行，刷新页面自动出现。没放的会显示虚线占位框，**不影响排版**，所以你可以先看整体效果再补图。

### 3. 导出 PDF

浏览器打开 `index.html` → 右上角「导出 PDF」按钮。

打印设置建议：
- 目标：**另存为 PDF**
- 边距：**默认**
- 勾选 **背景图形**（否则色块和表头底色会丢）
- 缩放：**默认 / 100%**

### 4. 发布网页版（可选）

推到 GitHub 仓库 → Settings → Pages → Source 选分支根目录（或把 `portfolio/` 设为发布目录）。

发布后链接形如 `https://<用户名>.github.io/<仓库名>/portfolio/`，放进简历即可。

## 内容结构

```
封面        项目名 + 一句话 + 5 个关键数字
1 问题      为什么搜索框接不住"场景" + 逐个判断"规则能解 / AI 能解"
2 方案      三件事 + 系统架构图（内联 SVG，不依赖外部图片）
3 产品      店铺页 / 场景组包 / 预算重配 / 一行代码嵌入
4 关键决策  5 条，每条都写明"取舍"
5 工程证据  测试输出 + 真实修过的 8 个问题 + 工程约束
6 复盘      做对了什么 / 已知不足 / 下一步
English Summary  一页英文摘要，海外投递时可直接单独打印
```

## 改内容

所有文字都在 `index.html` 里，没有构建步骤，改完刷新即可。

几个注意点：

- **架构图是内联 SVG**，不依赖图片文件，改了文字要顺手检查 `viewBox` 内的坐标
- **截图占位**用的是 `onerror` 回退：图片存在就显示图片，不存在就显示虚线框。想换成别的文件名，改 `src` 即可
- **打印样式**在 `<style>` 末尾的 `@media print` 里，改字号/边距都在那一段

## 英文版

`English Summary` 那一节目前是页面末尾的一个区块。

如果要做**独立的英文作品集**，最省事的做法是复制 `index.html` 为 `index-en.html`，
把中文段落整体替换掉即可——CSS 和图表都不用动。
