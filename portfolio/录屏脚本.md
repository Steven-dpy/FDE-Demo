# Nook · 2 分钟演示录屏脚本

> 目标：让一个**不懂技术**的 HR 看完就明白"这人做了个什么、解决了什么问题"。
> 原则：**问题讲 20 秒，产品演示占 80 秒，技术一笔带过。**

---

## 录制前准备

### 环境

```bash
cd nook/app && python server.py 8770
```

浏览器打开 `http://127.0.0.1:8770/`，然后：

| 准备项 | 设置 |
|---|---|
| 浏览器窗口 | 宽度 **1280–1440**，高度尽量大（商品卡不被裁） |
| 缩放 | **100%**（125% 录出来字会发虚） |
| 书签栏 | 隐藏（`Ctrl+Shift+B`） |
| 其他标签页 | 全关，只留这两个：`/` 和 `/embed.html` |
| 通知 | 开免打扰，别让微信弹窗进画面 |
| 深色模式 | 建议**浅色**录屏（投影和手机上看更清楚） |

### 录制工具

- **Win + G**（Xbox Game Bar）—— 系统自带，够用
- 或 **OBS Studio** —— 免费，画质更好，能加麦克风降噪
- 分辨率 **1920×1080 / 30fps** 就够，别录 4K（文件太大）

### 先彩排一遍

**关掉录音，空跑一次**，主要是确认：
- Nook 面板打开后商品卡都加载出来了（图片没挂）
- 「预算一万」那一步真的出现了「在你 ¥10,000 的预算内」
- 每一步的等待时间不超过 3 秒（超了就剪掉）

---

## 时间轴与旁白逐字稿

> 格式：`时间` ｜ `画面` ｜ **旁白**

### 0:00 – 0:18　开场：把问题说清楚

**画面**：Fern & Oak 店铺页首屏，鼠标缓慢滚一下商品网格。

**旁白**：

> "买家具的人，大多数进店的时候**不知道自己想要什么**。
> 他们不会在搜索框里打'北欧风格 实木 三人沙发'——那是买完的人才会说的话。
> 他们真正会说的是一句：**'我想弄个能窝着看书的地方。'**
> 而这句话，搜索框接不住。"

🎯 **这一段的唯一任务**：让 HR 在前 18 秒就理解"这是个真问题"。

---

### 0:18 – 0:35　演示一：模糊需求进去，成套方案出来 ★

**画面**：
1. 点右下角「问问 Nook」，面板弹出
2. 鼠标点快捷问题 **「我想弄个能窝着看书的地方」**
3. 等结果出现，**停留 3 秒不动**（让 HR 看清）

**旁白**：

> "我输入这句话。注意它**没有去找名字里带'看书'的商品**——
> 它识别出这是一个**'阅读角'**场景。
> 然后给的不是一件家具，是**一整套**：一把能坐一小时的椅子、一盏从肩后照过来的灯、
> 一个放杯子的台面，还带总价。"

🎯 **这是全片最重要的一段。** 停留那 3 秒不要省。

---

### 0:35 – 0:55　演示二：多轮追加约束

**画面**：
1. 在输入框打 **「预算一万」**，回车
2. 结果刷新后，**鼠标移到第一条商品的推荐理由上**，停在「在你 ¥10,000 的预算内」

**旁白**：

> "它还会追问预算，然后**重新配一套**。
> 这里有个细节：界面是中文的，所以我说的'一万'被当成人民币，
> 换算成美元去筛商品，但回显给我的还是**我自己说的那个数**——
> 不然我输入一万、它回我九千九百九十四，我会以为它算错了。"

🎯 这段是给**技术面试官**看的钩子——它说明你在意细节，而不是只跑通功能。

---

### 0:55 – 1:20　演示三：一行代码，嵌进任何网站 ★

**画面**：
1. 切到 `/embed.html`（一个风格完全不同的**深色**网站）
2. 滚动一下，让 HR 看清这是个不一样的站点
3. 点右下角 Nook 按钮，面板弹出

**旁白**：

> "刚才那个 Nook 是装在家具店里的。现在换一个网站——
> 这是个深色的、衬线字体的编辑类站点，风格完全不一样。
> 但我**只加了一行代码**，同一个 Nook 就装进来了。
> 而且注意：它在这里**还是绿色圆角的**，没有被这个网站的深色样式污染，
> 也没有把这个网站原来的样式搞乱。
> 这对要交付给客户的组件来说，是**能不能装上的前提**。"

🎯 如果时间不够，这段可以砍到 15 秒，但**不能整段砍掉**——它是"这是给别人用的产品"和"这是我自己的项目"的分界线。

---

### 1:20 – 1:45　技术底座（一笔带过，别展开）

**画面**：切回终端，跑一次测试。

```bash
cd nook/app && python selfcheck.py && python test_api.py
```

滚动到能看到 `RESULT: 16 checks passed` / `17 passed, 0 failed`。

**旁白**：

> "底下是 240 件商品的完整数据，中英双语。
> 整个系统**零第三方依赖**，不接任何外部 AI 服务也能跑。
> 33 项自动化测试，其中有一项是**硬性检查**：
> 推荐出来的每一个商品、每一个价格，都必须真实存在于数据库里——
> 电商场景里，编一个不存在的商品或价格是直接的法律风险。"

🎯 **不要念技术栈。** 不要说"我用了 XX 框架、XX 向量库"——HR 听不懂，面试官不需要你念。

---

### 1:45 – 2:00　收尾

**画面**：回到店铺页，Nook 面板开着。

**旁白**：

> "一句话总结：
> **我把'我不知道要买什么'这句话，变成了一套可以直接下单的方案。**
> 代码、测试、以及一个可以在浏览器里直接跑的静态演示版，都在仓库里。"

---

## 录完之后

1. **剪掉所有等待**——超过 3 秒的加载一律裁掉，节奏要快
2. **加字幕**——HR 很可能静音看。关键句一定要有字幕：
   - "搜索框接不住这句话"
   - "识别的不是关键词，是场景"
   - "一行代码，嵌进任何网站"
3. **导出 1080p MP4**，控制在 **20 MB 以内**
4. **上传到 B 站 / YouTube**（别只发文件），标题写：
   `Nook · 可嵌入独立站的 AI 导购引擎｜2 分钟演示`
5. 链接放进简历和作品集 PDF 的第一页

---

## 常见错误（别犯）

| ❌ 别做 | 为什么 |
|---|---|
| 开头介绍"大家好我是某某，今天给大家演示…" | 浪费前 10 秒。HR 可能只看前 15 秒 |
| 念技术栈（"我用了 Python、FastAPI、LangChain…"） | HR 听不懂，面试官不需要 |
| 鼠标乱晃、犹豫地点来点去 | 显得不熟练。每个动作提前彩排走位 |
| 录整个屏幕（含任务栏、书签、聊天窗口） | 不专业。只录浏览器窗口 |
| 视频放本地文件发微信 | 会被压缩得看不清。传到 B 站/YouTube |
| 超过 3 分钟 | HR 不会看完。**两分钟是上限** |

---

## 如果只能录 60 秒

砍掉：0:00 开场压到 8 秒、砍掉演示二（预算）、砍掉技术底座。

保留：**模糊需求 → 成套方案**（20 秒）+ **一行代码嵌入**（20 秒）+ 收尾（10 秒）。

这两段就是整个项目的全部价值。
